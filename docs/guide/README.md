# DebDroid Guides

Start here. These pages are written for anyone who can install an app and type
into a terminal. They tell you what to do, not how DebDroid works inside.

If you want to know how it works, that is in the
[reference section](../reference/README.md).

## A note on what this needs

DebDroid needs a **rooted** device. That is the trade: because it has root, it
runs real Debian programs rather than rebuilt ones, so almost anything in the
Debian archive works. If your device is not rooted, DebDroid cannot run on it.
